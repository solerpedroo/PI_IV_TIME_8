# Changelogs

Um arquivo por sessão/entrega relevante, mais detalhado que uma mensagem de
commit — pensado para dar contexto de handoff entre sessões do Claude Code:
não só "o que mudou", mas por quê, quais bugs reais apareceram e o que ficou
pendente. Ordem cronológica reversa (mais novo no topo).

Ao terminar uma sessão de trabalho relevante, crie um novo arquivo
`AAAA-MM-DD-titulo-curto.md` aqui e adicione a entrada abaixo.
